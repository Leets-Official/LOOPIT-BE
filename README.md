## 📖 Project Overview
### **LOOPIT**은 중고 IT 기기 판매, 근처 IT기기 수리점 탐색 및 챗봇을 통해<br> 수리비 견적 솔루션을 제공하는 플랫폼입니다<br>
이 리포지토리는 LOOPIT의 핵심 비즈니스 로직과 데이터 처리를 담당하는 **RESTful API 서버**입니다.<br>

### 🌐 Deployment

🔗 Service URL: https://www.loopit.kro.kr/
